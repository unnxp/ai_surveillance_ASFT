# กฎความปลอดภัยและการพัฒนาในพื้นที่ทำงาน (Workspace Rules)

* **กฎการแก้ไขไฟล์ (User Consent Rule):** AI Agent จะต้องทำการอธิบายแผนงาน รายละเอียดไฟล์ที่จะแก้ไข/สร้าง และต้องได้รับความเห็นชอบหรือคำสั่งอนุมัติอย่างเป็นลายลักษณ์อักษรจากผู้ใช้ก่อนที่จะเริ่มทำการเรียกใช้เครื่องมือเขียนหรือแก้ไขไฟล์ใดๆ เสมอ ห้ามดัดแปลงซอร์สโค้ด รันคำสั่ง หรือดาวน์โหลดไฟล์โมเดลเพิ่มโดยไม่ได้รับอนุญาต
