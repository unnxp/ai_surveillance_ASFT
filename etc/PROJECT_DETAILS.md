# เอกสารรายละเอียดโครงงาน (Project Details Specification)
## ระบบเฝ้าระวังพื้นที่อัจฉริยะ (AI-Based Smart Surveillance System)

เอกสารฉบับนี้จัดทำขึ้นเพื่อแสดงข้อกำหนด ขอบเขตงาน สถาปัตยกรรมระบบ และเทคโนโลยีปัญญาประดิษฐ์ (AI) ที่ใช้พัฒนาในระบบเฝ้าระวังพื้นที่อัจฉริยะแบบกระจายศูนย์ โดยเน้นความประหยัดแบนด์วิดท์เครือข่าย ความเป็นส่วนตัวของข้อมูล และความถูกต้องแม่นยำสูงในการจำแนกพฤติกรรม

---

## 1. ความเป็นมาและเป้าหมายของโครงการ (Project Background & Goals)
ระบบเฝ้าระวังความปลอดภัยดั้งเดิม (CCTV แบบเก่า) ต้องพึ่งพาเจ้าหน้าที่นั่งจ้องหน้าจอเป็นเวลานาน ซึ่งนำไปสู่ความผิดพลาดจากความล้าของมนุษย์ (Human Error) 
โครงการ **AI-Based Smart Surveillance System** มุ่งหวังที่จะเปลี่ยนผ่านโครงสร้างนี้โดยนำเสนอระบบวิเคราะห์ภาพสดอัตโนมัติ 24 ชั่วโมง โดยมีเป้าหมายหลักดังนี้:
1. **ลดการใช้แบนด์วิดท์เครือข่ายส่วนกลาง (>99.9%):** ด้วยการสกัดข้อมูลเป็นเวกเตอร์ตัวเลขขนาดเล็กที่กล้อง (Edge) และส่งเฉพาะข้อมูลจำเป็นไปตรวจหาคำตอบที่เซิร์ฟเวอร์ส่วนกลาง
2. **ตรวจจับและจำแนกเหตุร้ายแรงได้แม่นยำสูง (3-Class Schema):** ยุบรวมกลุ่มเหตุการณ์เหลือ 3 คลาสหลักที่มีนัยสำคัญต่อระบบรักษาความปลอดภัย เพื่อหลีกเลี่ยงความตื่นตูมของแบบจำลองและให้คะแนน F1-Score ในระดับปฏิบัติการได้จริง
3. **ตรวจสอบสิทธิ์ผู้เข้าพื้นที่ (Watchlist Verification):** เชื่อมโยงระบบตรวจจับการบุกรุกพื้นที่ Geofence เข้ากับระบบจดจำใบหน้าความเร็วสูง เพื่อคัดกรองพนักงานและระบุตัวตนบุคคลแปลกหน้า (Stranger)

## 2. ขอบเขตการทำงานหลักของระบบ (System Scope)

ระบบแบ่งขอบเขตงานการวิเคราะห์ออกเป็น 4 ฟังก์ชันสำคัญ:

* **2.1. ระบบจดจำใบหน้า (Facial Recognition):**
  - ค้นหาพิกัดใบหน้าและจุดแลนด์มาร์กสำคัญด้วยโมเดล **SCRFD**
  - ปรับมุมเอียงใบหน้าให้หันตรง (Affine Alignment) ขนาด $112 \times 112$ พิกเซล
  - สกัดคุณลักษณะจำเพาะของใบหน้าเป็นเวกเตอร์ 512 มิติด้วยโมเดล **ArcFace**
  - เปรียบเทียบระบุตัวตนข้ามฐานข้อมูลพนักงาน/Watchlist ด้วย Cosine Similarity บนระบบจำลอง **1:N Search** ได้ผลลัพธ์แม่นยำ **94.67%** (สถิติจาก Faces-Dataset 2,562 รูป) โดยใช้เกณฑ์ตัดสินความคล้ายคลึง (Decision Threshold) อยู่ที่ **`0.3275`** (หากต่ำกว่านี้ระบบจะจัดประเภทเป็นคนแปลกหน้า Unknown เพื่อความปลอดภัย)
* **2.2. ระบบตรวจจับการบุกรุกพื้นที่หวงห้าม (Intrusion Detection):**
  - ตรวจจับความเคลื่อนไหวและติดตามตัวบุคคล
  - กำหนดและปรับแต่งพื้นที่เสี่ยง (Geofence Polygon) ได้แบบไดนามิกผ่านเครื่องมือช่วยวาด
  - ประเมินและส่งเสียงเตือนภัยเมื่อมีบุคคลบุกรุกข้ามเส้นกั้นหรือพื้นที่เสี่ยงนอกเวลาทำการ (Off-Hours) โดยสแกนระบบ Geofencing แบบ 3 จุดพร้อมกัน (เท้า, เข่า, ลำตัว) เพื่อกันปัญหามุมกล้องอับสัญญาณ
* **2.3. โมเดลจำแนกพฤติกรรมผิดปกติและเหตุร้าย (Action & Crime Classifier):**
  - ใช้โมเดลโครงข่ายประสาทเทียม **EfficientNet-B0 + Temporal GRU**
  - บูรณาการชุดข้อมูลขนาดใหญ่รวม 3 แหล่งดักจับ (UCF-Crime, Youtube Robbery, และ SCVD-Violence) รวมทั้งสิ้น **1,371 วิดีโอ** ในชุดฝึกสอน
  - จำแนกพฤติกรรมความปลอดภัยเป็น **3 คลาสหลัก** ได้แก่:
    - **0: Normal** (เหตุการณ์ปกติทั่วไป เช่น ยืน นั่ง เดิน พนักงานขยับตัวทำงาน)
    - **1: Property_Crime** (ภัยคุกคามต่อทรัพย์สิน เช่น โจรกรรม งัดแงะ ลักขโมย ทำลายทรัพย์สิน)
    - **2: Personal_Violence** (ความรุนแรงต่อร่างกาย เช่น ชกต่อย ทำร้ายร่างกาย ใช้อาวุธทำร้าย)
  - ทำการประมวลผลวิดีโอด้วยระบบ **Bounding Box Centering (Margin 50%):** ล็อกตัวเป้าหมายให้อยู่ใจกลางเฟรม Letterbox สีดำ ทำหน้าที่เสมือนตัวกันสั่นสะเทือน (Stabilizer) และขยายระยะครอป 50% เพื่อรักษาปฏิสัมพันธ์ระหว่างคนร้ายกับสิ่งของแวดล้อม (Human-Object Interaction)
  - ติดตั้งตัวกรองความมั่นใจ **Confidence Threshold Filter (70%):** หากตรวจพบเหตุร้าย (คลาส 1 หรือ 2) แต่ค่าความน่าจะเป็นต่ำกว่า 70% ระบบจะปรับผลลัพธ์ย้อนเป็น Normal เพื่อป้องกันปัญหาสัญญาณเตือนภัยมั่ว (False Alarm)
* **2.4. การนับจำนวนและแผนที่ความร้อน (People Counting & Heat Mapping):**
  - นับจำนวนคนในเฟรมเรียลไทม์ และยอดคนสะสมที่เดินผ่านโซน
  - สร้างแผนภาพสะสมความร้อน (Heatmap) บีบอัดเป็นตารางสรุปขนาด $32 \times 32$ พิกเซล ประจำกล้อง เพื่อวิเคราะห์ความหนาแน่นผู้ใช้งานพื้นที่และประหยัดแบนด์วิดท์เครือข่าย

## 3. สถาปัตยกรรมระบบแบบกระจายศูนย์ (Distributed Architecture)

### 🔹 3.1. งานของกล้องประมวลผลปลายทาง (Local Edge Node)
กล้องวงจรปิดแต่ละตัวจะเชื่อมเข้ากับคอมพิวเตอร์ประมวลผลย่อยในพื้นที่ ทำหน้าที่วิเคราะห์ข้อมูลทางกายภาพทั้งหมด:
1. **รันตัวตรวจจับวัตถุและคีย์พอยท์:** YOLOv8 (สำหรับค้นหาบุคคล) และ SCRFD (สำหรับหาใบหน้า)
2. **สกัดรูปใบหน้าและจัดสเกล:** ทำ Face Alignment และป้อนเข้าโมเดล ArcFace เพื่อแปลงภาพถ่ายเป็นเวกเตอร์ 512 มิติ
3. **วิเคราะห์พฤติกรรมท้องถิ่น:** ตรวจเช็คการล้ำเส้น Geofence, สุ่มตัดเฟรมวิดีโอ 32 เฟรมล่าสุดของแต่ละบุคคลเพื่อประเมินผ่านโมเดล **EfficientNet-B0 + GRU** หาสัญญาณประเภทพฤติกรรม (3 คลาส)
4. **สะสมค่าความร้อน:** วาดแผนที่สะสมความหนาแน่นลงตารางเมทริกซ์ 2D ท้องถิ่น และบีบอัดความร้อนเป็นตารางสรุปขนาด $32 \times 32$ พิกเซล
5. **ส่งแพ็กเกจเวกเตอร์ย่อย:** รวมข้อมูลเวกเตอร์ใบหน้า สถานะบุกรุก และชื่อคลาสพฤติกรรม แพ็กเป็น JSON ส่งไปยังส่วนกลางผ่านเครือข่ายความเร็วสูง (<4 KB)

### 🔸 3.2. งานของเซิร์ฟเวอร์ปัญญาประดิษฐ์ส่วนกลาง (Central AI Server)
เซิร์ฟเวอร์ส่วนกลางทำหน้าที่วิเคราะห์เชิงตรรกะระดับสูงและเชื่อมโยงบริบทความปลอดภัย (Context Fusion):
1. **ระบบจดจำใบหน้าความมั่นใจสูง:** ค้นหาระบุตัวตนพนักงาน หรือบุคคล Blacklist ใน Watchlist ด้วยการคำนวณ Cosine Similarity เทียบกับเกณฑ์ Threshold `0.3275`
2. **ประเมินสิทธิ์การเข้าพื้นที่ (Access Authorization):** วิเคราะห์ร่วมว่าบุคคลที่เดินผ่าน Geofence เป็นพนักงาน (Authorized) หรือเป็นคนแปลกหน้า (Unknown) และตรวจเช็คเงื่อนไขเวลากลางคืน (Off-Hours)
3. **ประเมินระดับความเสี่ยง (Risk Assessment MLP Engine):** ใช้โมเดล PyTorch MLP รับค่าฟีเจอร์พฤติกรรม 6 มิติ (Geofence status, loitering duration, speed, time of day, person count, และ action class) เพื่อทำนายระดับความเสี่ยง 4 ระดับ (LOW / MEDIUM / HIGH / CRITICAL) พร้อมแสดงค่าความมั่นใจ (%) แบบเรียลไทม์ แทนลอจิก if-else ดั้งเดิม
4. **บันทึกประวัติและส่งเสียงเตือน:** สั่งรัน Alert Manager บันทึกภาพถ่ายวินาทีเกิดเหตุ บันทึกตารางเหตุการณ์ลงไฟล์ CSV/Database และอัปเดตระบบแดชบอร์ด

## 4. เทคโนโลยีและชุดโมดูลปัญญาประดิษฐ์ (Technology Stack)

| ส่วนงานประมวลผล | โมเดล / ไลบรารีปัญญาประดิษฐ์ | บทบาทและขอบเขตงาน |
| :--- | :--- | :--- |
| **Face Detection** | **SCRFD** (InsightFace) | ตรวจจับใบหน้าคนและจุดแลนด์มาร์กสำคัญ 5 จุดอย่างรวดเร็วและทนทานต่อการหันเอียง |
| **Face Embedding** | **ArcFace ONNX (w600k_r50)** | สกัดรหัสใบหน้า 512 มิติ (Normalized Feature Vector) |
| **Object Detection & Tracking** | **YOLOv8 + ByteTrack** | ตรวจจับและวิเคราะห์ติดตามทิศทางบุคคล และพิกัด Geofence |
| **Action Classifier** | **EfficientNet-B0 + GRU (PyTorch)** | โมเดลตรวจจำและจำแนกเหตุผิดปกติ 3 คลาส ด้วยการเทรนร่วมของ 3 Datasets เสริม |
| **Weighted Sampler** | **Square-Root Sampler ($\alpha=0.5$)** | ตัวช่วยเกลี่ยสมดุลการสุ่มข้อมูลและลดการแจ้งเตือนเหตุร้ายมั่ว (False Alarm) |
| **Risk Classifier** | **Feed-Forward MLP (PyTorch)** | โมเดลเครือข่ายประสาทเทียมทำนายระดับความเสี่ยงจากสถิติพฤติกรรม 6 มิติ |
| **Graphic & Core Pipeline** | **OpenCV + ONNX Runtime** | จัดการกระบวนการสตรีมภาพสด, หมุนองศา Affine Transformation, และวาดภาพความร้อนซ้อนทับภาพสด |
| **Backend & Communication** | **FastAPI + REST API / WebSockets** | ประสานงานแลกเปลี่ยนสัญญาณและเวกเตอร์ระหว่างกล้องปลายทางกับเซิร์ฟเวอร์ส่วนกลาง |

## 5. แผนการตรวจสอบความถูกต้องของระบบ (System Verification)

1. **การตรวจสอบโมเดลจำแนกพฤติกรรม 3 คลาส:**
   - ประเมินผลลัพธ์จำแนกเหตุร้ายบนชุดข้อมูลทดสอบรวม `test_3cls.txt` จำนวน **326 วิดีโอ** โดยเน้นการรักษาสมดุลความครอบคลุม (Recall) และจำกัดการแจ้งเตือนมั่ว (Precision) ในคลาสคดีทรัพย์สินและความรุนแรง
2. **การตรวจสอบโมเดลจดจำใบหน้า 1:N Watchlist:**
   - ทดสอบสืบค้นเปรียบเทียบลายนิ้วมือเวกเตอร์ใบหน้าข้ามฐานข้อมูลด้วยชุดข้อมูลอ้างอิง Faces-Dataset พบว่าระบบระบุพิกัดสิทธิ์บุคคลได้ความแม่นยำ Top-1 Accuracy สูงถึง **$94.67\%$**
3. **การตรวจสอบผลลัพธ์หน้างาน (Manual Functional Testing):**
   - ทดสอบจำลองการสตรีมภาพสดจากกล้อง IP ผ่านสตรีม RTSP
   - ตรวจดูความนิ่งของระบบ Bounding Box Centering และตัวกรองความมั่นใจ (Threshold Filter 70%) ในการควบคุม False Positives
