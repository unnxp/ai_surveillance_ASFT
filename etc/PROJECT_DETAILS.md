# เอกสารรายละเอียดโครงงาน (Project Details Specification)
## ระบบเฝ้าระวังพื้นที่อัจฉริยะ (AI-Based Smart Surveillance System)

เอกสารฉบับนี้จัดทำขึ้นเพื่อแสดงข้อกำหนด ขอบเขตงาน สถาปัตยกรรมระบบ และเทคโนโลยีปัญญาประดิษฐ์ (AI) ที่ใช้พัฒนาในระบบเฝ้าระวังพื้นที่อัจฉริยะแบบกระจายศูนย์ โดยเน้นความประหยัดแบนด์วิดท์เครือข่าย ความเป็นส่วนตัวของข้อมูล และความถูกต้องแม่นยำสูงในการจำแนกพฤติกรรม

---

## 1. ความเป็นมาและเป้าหมายของโครงการ (Project Background & Goals)
ระบบเฝ้าระวังความปลอดภัยดั้งเดิม (CCTV แบบเก่า) ต้องพึ่งพาเจ้าหน้าที่นั่งจ้องหน้าจอเป็นเวลานาน ซึ่งนำไปสู่ความผิดพลาดจากความล้าของมนุษย์ (Human Error) 
โครงการ **AI-Based Smart Surveillance System** มุ่งหวังที่จะเปลี่ยนผ่านโครงสร้างนี้โดยนำเสนอระบบวิเคราะห์ภาพสดอัตโนมัติ 24 ชั่วโมง โดยมีเป้าหมายหลักดังนี้:
1. **ลดการใช้แบนด์วิดท์เครือข่ายส่วนกลาง (>99.9%):** ด้วยการสกัดข้อมูลเป็นเวกเตอร์ตัวเลขขนาดเล็กที่กล้อง (Edge) และส่งเฉพาะข้อมูลจำเป็นไปตรวจหาคำตอบที่เซิร์ฟเวอร์ส่วนกลาง
2. **ตรวจจับและจำแนกเหตุร้ายแรงได้ครอบคลุม 21 ประเภท:** โดยใช้ข้อมูลจริงจากชุดข้อมูลเพื่อสอนปัญญาประดิษฐ์ให้สามารถเตือนภัยภัยคุกคามในรูปแบบต่างๆ ได้โดยไม่ต้องพึ่งพาลอจิกแบบเงื่อนไขกฎเดิม
3. **ตรวจสอบสิทธิ์ผู้เข้าพื้นที่:** เชื่อมโยงระบบตรวจจับการบุกรุกพื้นที่ Geofence เข้ากับระบบจดจำใบหน้าความเร็วสูง เพื่ออำนวยความสะดวกให้ผู้มีสิทธิ์ และป้องกันบุคคลอันตราย

## 2. ขอบเขตการทำงานหลักของระบบ (System Scope)

ระบบแบ่งขอบเขตงานการวิเคราะห์ออกเป็น 4 ฟังก์ชันสำคัญ:

* **2.1. ระบบจดจำใบหน้า (Facial Recognition):**
  - ค้นหาพิกัดใบหน้าและจุดแลนด์มาร์กสำคัญด้วยโมเดล **SCRFD**
  - ปรับมุมเอียงใบหน้าให้หันตรง (Affine Alignment) ขนาด $112 \times 112$ พิกเซล
  - สกัดคุณลักษณะจำเพาะของใบหน้าเป็นเวกเตอร์ 512 มิติด้วยโมเดล **ArcFace**
  - เปรียบเทียบระบุตัวตนข้ามฐานข้อมูลพนักงาน/Blacklist ด้วยฐานข้อมูลเวกเตอร์ความเร็วสูง **FAISS**
* **2.2. ระบบตรวจจับการบุกรุกพื้นที่หวงห้าม (Intrusion Detection):**
  - ตรวจจับความเคลื่อนไหวและติดตามตัวบุคคล
  - กำหนดและปรับแต่งพื้นที่เสี่ยง (Geofence Polygon) ได้แบบไดนามิกผ่านเครื่องมือช่วยวาด
  - ประเมินและส่งเสียงเตือนภัยเมื่อมีบุคคลบุกรุกข้ามเส้นกั้นหรือพื้นที่เสี่ยงนอกเวลาทำการ
* **2.3. โมเดลจำแนกพฤติกรรมผิดปกติและเหตุร้าย (Action & Crime Classifier):**
  - ใช้โมเดลโครงข่ายประสาทเทียม **EfficientNet-B0 + Temporal GRU**
  - จำแนกเหตุการณ์ผิดปกติและความรุนแรงรวม **21 คลาส** (เทรนจากชุดข้อมูลจริงใน `exampleDataset`) ได้แก่:
    - *ภัยคุกคามและอาวุธ:* การทำลายทรัพย์สิน (Vandalism), ขโมย (Stealing), ลักขโมยของในร้าน (Shoplifting), เหตุยิงปืน (Shooting), จี้ชิงทรัพย์ (Robbery), รถชน (Roadaccidents), ทะเลาะวิวาท (Fighting), ระเบิด (Explosion), งัดแงะ (Burglary), ทำร้ายร่างกาย (Assault), วางเพลิง (Arson), ถูกจับกุม (Arrest), ทารุณกรรม (Abuse)
    - *พฤติกรรมทั่วไป:* ปกติ (Normal), เดิน (Walking), เล่นมือถือขณะเดิน (Walking_Phone), อ่านหนังสือขณะเดิน (Walking_Book), ยืนนิ่ง (Standing), นั่ง (Sitting), พบปะ/แยกย้าย (Meet_Split), ปรบมือ (Clapping)
* **2.4. การนับจำนวนและแผนที่ความร้อน (People Counting & Heat Mapping):**
  - นับจำนวนคนในเฟรมเรียลไทม์ และยอดคนสะสมที่เดินผ่านโซน
  - สร้างแผนภาพสะสมความร้อน (Heatmap) ประจำกล้อง เพื่อวิเคราะห์ความหนาแน่นผู้ใช้งานพื้นที่
  - แจ้งเตือนความแออัดของฝูงชน (Overcrowding Warning) เมื่อมีจำนวนคนเกาะกลุ่มกันหนาแน่นเกินพิกัดกำหนด

## 3. สถาปัตยกรรมระบบแบบกระจายศูนย์ (Distributed Architecture)

เพื่อลดแบนด์วิดท์เครือข่าย ระบบจึงกระจายโหลดงานการคำนวณออกเป็น 2 ส่วน:

### 🔹 3.1. งานของกล้องประมวลผลปลายทาง (Local Edge Node)
กล้องวงจรปิดแต่ละตัวจะเชื่อมเข้ากับคอมพิวเตอร์ประมวลผลย่อยในพื้นที่ ทำหน้าที่วิเคราะห์ข้อมูลทางกายภาพทั้งหมด:
1. **รันตัวตรวจจับวัตถุและคีย์พอยท์:** YOLOv8 (สำหรับค้นหาบุคคล) และ SCRFD (สำหรับหาใบหน้า)
2. **สกัดรูปใบหน้าและจัดสเกล:** ทำ Face Alignment และป้อนเข้าโมเดล ArcFace เพื่อแปลงภาพถ่ายเป็นเวกเตอร์ 512 มิติ
3. **วิเคราะห์พฤติกรรมท้องถิ่น:** ตรวจเช็คการล้ำเส้น Geofence, สุ่มตัดเฟรมวิดีโอ 16 เฟรมล่าสุดของแต่ละบุคคลเพื่อประเมินผ่านโมเดล **EfficientNet-B0 + GRU** หาสัญญาณประเภทพฤติกรรม
4. **สะสมค่าความร้อน:** วาดแผนที่สะสมความหนาแน่นลงตารางเมทริกซ์ 2D ท้องถิ่น และบีบอัดความร้อนเป็นตารางสรุปขนาด $32 \times 32$ พิกเซล
5. **ส่งแพ็กเกจเวกเตอร์ย่อย:** รวมข้อมูลเวกเตอร์ใบหน้า สถานะบุกรุก และชื่อคลาสพฤติกรรม แพ็กเป็น JSON ส่งไปยังส่วนกลางผ่านเครือข่ายความเร็วสูง (<4 KB)

### 🔸 3.2. งานของเซิร์ฟเวอร์ปัญญาประดิษฐ์ส่วนกลาง (Central AI Server)
เซิร์ฟเวอร์ส่วนกลางทำหน้าที่วิเคราะห์เชิงตรรกะระดับสูงและเชื่อมโยงบริบทความปลอดภัย (Context Fusion):
1. **ฐานข้อมูลเวกเตอร์ส่วนกลาง (FAISS Vector Database):** ค้นหาเปรียบเทียบพาสเวิร์ดเวกเตอร์ 512 มิติที่ยิงมาจากกล้อง เพื่อระบุชื่อพนักงาน หรือตัวตน Blacklist ทันที (<1ms)
2. **ประเมินสิทธิ์การเข้าพื้นที่ (Access Authorization):** วิเคราะห์ร่วมว่าบุคคลที่เดินผ่าน Geofence เป็นพนักงาน (Authorized) หรือเป็นคนแปลกหน้า (Unknown) และตรวจเช็คเงื่อนไขเวลากลางคืน (Off-Hours)
3. **ตัดระดับความเสี่ยง (Risk Assessment Engine):** นำผลลัพธ์พฤติกรรม 21 คลาส และความแออัดของฝูงชนมารวมคะแนนความเสี่ยงเพื่อแบ่งระดับการเตือนภัย (LOW / MEDIUM / HIGH / CRITICAL)
4. **บันทึกประวัติและส่งเสียงเตือน:** สั่งรัน Alert Manager บันทึกภาพถ่ายวินาทีเกิดเหตุ บันทึกตารางเหตุการณ์ลงไฟล์ CSV/Database และอัปเดตระบบแดชบอร์ด

## 4. เทคโนโลยีและชุดโมดูลปัญญาประดิษฐ์ (Technology Stack)

| ส่วนงานประมวลผล | โมเดล / ไลบรารีปัญญาประดิษฐ์ | บทบาทและขอบเขตงาน |
| :--- | :--- | :--- |
| **Face Detection** | **SCRFD** (InsightFace) | ตรวจจับใบหน้าคนและจุดแลนด์มาร์กสำคัญ 5 จุดอย่างรวดเร็วและทนทานต่อการหันเอียง |
| **Face Embedding** | **ArcFace ONNX** | สกัดรหัสใบหน้า 512 มิติ (Normalized Feature Vector) |
| **Vector Search** | **FAISS** (Meta AI) | ค้นหาและคำนวณเปรียบเทียบระยะเวกเตอร์ใบหน้าความเร็วสูง (Cosine Similarity) |
| **Object Detection & Tracking** | **YOLOv8 + BoT-SORT / ByteTrack** | ตรวจจับและวิเคราะห์ติดตามทิศทางบุคคล และพิกัด Geofence |
| **Action & Crime Model** | **EfficientNet-B0 + GRU (PyTorch)** | โมเดลตรวจจำและจำแนกเหตุผิดปกติ 21 คลาสตามฐานข้อมูล `exampleDataset` |
| **Graphic & Core Pipeline** | **OpenCV + ONNX Runtime** | จัดการกระบวนการสตรีมภาพสด, หมุนองศา Affine Transformation, และวาดภาพความร้อนซ้อนทับภาพสด |
| **Backend & Communication** | **FastAPI + REST API / WebSockets** | ประสานงานแลกเปลี่ยนสัญญาณและเวกเตอร์ระหว่างกล้องปลายทางกับเซิร์ฟเวอร์ส่วนกลาง |

## 5. แผนการตรวจสอบความถูกต้องของระบบ (System Verification)

1. **การตรวจสอบโมเดลแบบอัตโนมัติ (Automated Testing):**
   - ตรวจสอบความถูกต้องของการจำแนกพฤติกรรม 21 คลาสบนชุดข้อมูลทดสอบ (Test Set) ในไฟล์ `test.txt` โดยจะต้องได้ค่าความแม่นยำ (Accuracy) และค่า F1-Score ในแต่ละกลุ่มหลักมากกว่า 90%
2. **การตรวจสอบผลลัพธ์หน้างาน (Manual Functional Testing):**
   - ทดสอบจำลองการสตรีมภาพสดจากกล้อง IP ทั้งสองตัวขนานกัน
   - ตรวจดูว่า Bounding Box และแผนภาพ Heatmap ซ้อนทับพิกัดได้เสถียร
   - ทดลองเดินล้ำเส้น Geofence และจำลองใบหน้าคนแปลกหน้า สังเกตการเปรียบเทียบใน FAISS และการสร้างไฟล์หลักฐานแจ้งเตือนในระบบส่วนกลาง
